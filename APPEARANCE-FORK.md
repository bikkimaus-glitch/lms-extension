# Формы кнопок и видеофон

Доработка CU LMS Enhancer, основанная на upstream 217b0a3 (2.8.3).
Изменённые файлы сохраняют лицензию MPL-2.0 оригинального проекта.

## Установка

Chrome: распакуйте `lms-extension-custom-chrome.zip`, откройте
`chrome://extensions`, включите режим разработчика, нажмите «Загрузить
распакованное» и выберите папку с `manifest.json`. Если установлена магазинная
версия, отключите её на время работы с этой сборкой, чтобы два экземпляра не
изменяли страницу одновременно. Эта сборка не обновляется из магазина.

Firefox: распакуйте соответствующий архив и откройте manifest.json через
`about:debugging#/runtime/this-firefox` → Load Temporary Add-on. Такая установка
временная; для постоянной установки нужна подписанная сборка Mozilla.

## Форма кнопок

Меню расширения → Тема → Редактор темы → Палитра → «Форма и размеры кнопок».
Скругления 0–64 px и внутренние отступы задаются ползунками. Для контуров есть
прямоугольник, скошенные углы, параллелограмм, билет и собственный многоугольник.
Перетаскивайте точки на схеме или выбирайте точку и меняйте координаты X/Y.
Можно добавлять и удалять точки (3–16). Настройка включает свою тему и применяется
сразу во всех открытых вкладках LMS; выключатель возвращает форму базовой темы.

Контур работает через clip-path: точки идут по порядку по краю. Самопересечения
и узкий центр могут обрезать текст — оставляйте место под надпись и проверяйте
длинные кнопки. Вкладки role=tab и обычные ссылки сохраняют исходную геометрию.
Панели редактора в Shadow DOM не изменяются. Встроенные SVG внутри кнопок
сохраняются; новые формы не заменяют содержимое кнопок.

## Видеофон

Меню расширения → Оформление → Редактор фона. Выберите область: текущая
страница, курс, раздел или все страницы; нажмите «Фото или видео» и загрузите
MP4 (рекомендуется H.264) либо WebM (VP8/VP9) до 20 МБ. Поддержка кодека зависит
от браузера. Видео сохраняется локально без перекодирования и не загружается
на сервер. Прямые ссылки на сторонние видео в этой версии не поддерживаются.

Видео зациклено, всегда без звука. В редакторе доступны пауза, скорость
0.25–2×, подложка и заполнение экрана. Для видео «Плиткой» использует cover.
При скрытии вкладки воспроизведение приостанавливается; при системном
prefers-reduced-motion показывается неподвижный кадр. При ошибке кодека редактор
показывает сообщение. «Убрать» снимает фон выбранной области; выключатель своего
фона убирает и видео. Узкие области имеют приоритет перед общим фоном.

Чтобы сохранить форму, экспортируйте тему. Чтобы сохранить также видео,
экспортируйте профиль с группой «Логотип и фоны» / всеми настройками, включая
контент. Большие видео увеличивают размер JSON. Не загружайте видео в публичную
мастерскую случайно: публикация профиля с медиа передаёт включённые файлы.

## Проверки и разработка

Используйте Bun (AGENTS.md). `bun install --frozen-lockfile --ignore-scripts`
позволяет собрать Chrome/Firefox без необязательного macOS DMG-модуля.
`bun run build:chrome`, `bun run build:firefox`, `bun run lint`.
`bun test tests/source/appearance.test.ts` проверяет валидацию геометрии,
отключение формы, допустимые медиа и совместимость профилей.

Фон рисуется в фиксированных изолированных слоях непрозрачных полотен, чтобы
не раскрывать скрытое мобильное меню. Видео синхронизируются с ведущим слоем;
при смене области/отключении источники и object URL освобождаются. Разрешения
расширения не расширялись. Новые настройки:

- local.customThemeButtonShape (theme, валидируется перед генерацией CSS);
- sync.backgroundVideoPlayback, sync.backgroundVideoSpeed (appearance);
- видео data URL в существующих local.customBackground\* (content).
