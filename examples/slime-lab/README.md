# SLIME LAB

Экспериментальная тема с сильной плавной деформацией кнопок и окон. Вдохновение: гель, слизь, аморфные органические формы. Палитра — зелёный, мята и тёмный хвойный текст. Изображений и сгенерированной графики нет.

Откройте preview.html в современном Chrome или Firefox. Рядом должен лежать slime-effects.js. Вверху — пауза, скорость и экспорт темы с выбранной скоростью. Кнопки курсов открывают демонстрационное окно. Данные вымышленные.

Для установки в обновлённый форк: меню → Тема → Своя тема → Загрузить тему из файла → slime-lab.theme.json. Профиль выключает статический редактор контура, чтобы он не перебивал деформацию. Самого CSS недостаточно: нужен форк со slime_effects.js.

SVG displacement-фильтры искажают рисуемую поверхность, а текст остаётся читаемым. Контуры постоянно образуют выпуклости и впадины. Деформация строго ограничена коробкой каждого элемента через contain:paint: кнопки и панели не перекрывают соседей, раскладка и зоны клика стабильны.

Скорость по умолчанию 0.35×: цикл деформации примерно 20–26 секунд. При скрытии вкладки и включённом системном уменьшении движения анимация приостанавливается/отключается. Настройка скорости в предпросмотре входит в экспорт JSON.
